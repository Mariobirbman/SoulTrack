# UI Implementation Notes

Design guardrail source: local `uncodixfy` skill.

## Non-generic checklist
- Keep radii restrained (`6px` to `12px`) and avoid pill-heavy controls.
- Prefer dense, readable layouts over decorative hero/dashboard filler.
- Avoid floating glass shells, glow-heavy cards, and oversized shadows.
- Use semantic accents sparingly for state and action focus.
- Keep hierarchy clear with typography/spacing, not ornamental copy blocks.
- Maintain explicit labels and form associations (`for` + `id` + `name`).

# Site audit (what to add next)

This is a practical “what’s missing” list to help you ship a clean school project that still feels real.

## Ship-ready (high priority)
- Real copy: make the home page explain *who it’s for* and *why it’s useful* in 1–2 lines.
- Real data path: decide if `Browse`/`Vendors` are demo-only or truly backed by Firestore.
- Error states: confirm every page has a clear empty/loading/error state.
- Mobile QA: test navigation + forms on a small screen.
- Auth QA: register/login/logout; verify `My Account` is protected.

## Nice-to-have polish
- Add a footer with a short “about this project” + contact link.
- Add a “Feedback” link (Google Form) so users can report issues quickly.
- Add better image alt text (accessibility).
- Add simple “tour” copy on first login (what to do next).

## If you want real users
- Pick one niche: e.g. “high school sneaker resellers” or “new resellers tracking first 20 flips”.
- Recruit 10 testers: classmates + 1 local sneaker group + 1 Discord.
- Ask for 1 metric: “Did you log a sale?” (yes/no) + “What confused you?”
- Iterate weekly: ship 1 improvement per week based on feedback.
